# @memo-ai/opencode

OpenCode plugin for MeMo-AI.

- `index.ts` exposes a `memo_status` tool.
- `tui.tsx` renders the MeMo-AI wordmark in the home footer and adds a
  `MeMo-AI · About` palette command.

The plugin is installed automatically by `memo-ai install` under
`~/.config/opencode/plugins/memo-ai/`.
